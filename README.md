# DolceBar Angular

A frontend cafeteria and e-commerce application built with Angular 21 and TypeScript. The project uses local JSON data for academic and demonstration purposes.

## Features

- Product and category browsing
- Product details pages
- Shopping cart management
- User registration and login
- User profile pages
- Administrator features for managing products and users

## Technologies

- Angular 21
- TypeScript
- Angular Router
- Reactive Forms
- HTML and CSS
- Local JSON data

## Run Locally

```bash
git clone https://github.com/MohammedMosleh/DolceBar-Angular.git
cd DolceBar-Angular
npm install
npm start
```

Open `http://localhost:4200` in your browser.
