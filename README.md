DolceBar Angular

DolceBar Angular is a frontend cafeteria and e-commerce application built with Angular 21 and TypeScript. It demonstrates customer and administrator workflows through a component-based single-page application.

Features

Customer Experience

Browse products and navigate by category

View individual product details

Add products to a shopping cart and manage cart contents

Register, log in, and access a user profile

Administration

Access administrator functionality

Manage product and user information through dedicated application screens

Technology Stack

Angular 21

TypeScript

Angular Router

Reactive Forms

RxJS

HTML

CSS

Local JSON data

Application Design

The project uses Angular's component-based architecture to separate application screens and functionality. Angular Router handles navigation, while Reactive Forms support structured input handling and validation. Product and user data are stored locally in JSON for academic and demonstration purposes.

Run Locally

Prerequisites

Install a recent version of Node.js and npm that is compatible with Angular 21.

Installation

git clone https://github.com/MohammedMosleh/DolceBar-Angular.git
cd DolceBar-Angular
npm install
npm start

Open http://localhost:4200 in your browser.

Available Commands

npm start       # Start the development server
npm run build   # Create a production build
npm test        # Run the configured test command

Current Scope

This repository is a frontend academic project. It uses local JSON data instead of a deployed backend or persistent database. Authentication and data-management flows are intended as application demonstrations rather than production-ready security implementations.
